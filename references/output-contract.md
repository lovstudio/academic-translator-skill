# 图文完整论文译稿验收契约

## PDF 路线与页数约束

| 路线 | 适用场景 | 必须验收 |
| --- | --- | --- |
| `pdf2zh` 保版式 | 保留图片、图表、公式或原版式 | 页数/页尺寸、含图页、目录、参考文献 |
| `target-only` 重排 | 只需快速中文阅读稿 | 输出页数 = 源页数 |
| `facing-pages` 重排 | 需要逐页对照 | 输出页数 = 源页数 × 2，原文与译文紧邻 |
| `bilingual-expanded` 重排 | 需要逐段中英对照 | 逻辑页数相同，页面高度扩大 |

保版式路线中的图片、矢量图和公式是原始证据，不能因文字翻译失败而替换成概述。图内文字只在用户明确要求时处理；保留原图副本，并在图注标注本地化版本。

目录必须同时具备可读视觉样式和内部跳转，参考文献保持书目结构；这两类页面不以机器翻译覆盖为默认。

## 结构对齐

| 对象 | 默认处理 | 验收信号 |
| --- | --- | --- |
| 标题与章节 | 保留原层级与论证顺序 | 译稿 H1-H3 顺序与源稿一致 |
| 图片与图注 | 原图在原锚点附近，翻译图注 | 图片数量和顺序一致；每图可回溯到源稿 |
| 表格 | 保留列、行、单位和表题 | 表格数量相同或差异已说明 |
| 公式 | 原样保留 LaTex/MathML 与变量 | 块公式数量一致；符号未被翻译 |
| 代码 | 原样保留 | 代码块数量一致 |
| 引用 | 保留引文键、DOI、URL 和参考文献 | 链接数量差异可解释 |

## 图像处理决策

1. 优先使用原图：科研图、数据图、架构图和截图都是原始证据。
2. 翻译图注：中文图注要讲明图中展示什么、比较了什么、结论是什么；保留 `Figure N` / `图 N` 对应关系。
3. 处理图内文字：先补充图注或邻近说明。只有用户明确要中文图时，才编辑图片，并保留原图、标明本地化版本和来源。
4. 使用相对路径保存本地图片，例如 `assets/fig-03-attention.png`；不要留下只在本机可用的绝对路径。

## 发布前人工检查

- 抽样查看全部图片前后各一段：它们应支撑紧邻的论点。
- 检查长图、宽表、数学公式和代码块在目标渲染器中的换行。
- 检查图片的替代文本和图注；不要只写“图片”或“Figure”。
- 不把 `01-analysis.md`、术语讨论或内部背景带进 `translation.md`。
